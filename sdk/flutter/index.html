    Flutter SDK¶

    The ekyc_sdk Dart package wraps the Cloud Bhutan eKYC REST API and ships with an on-device active-liveness UI. Use it in Flutter mobile and Dart server projects to call face verification, document OCR, liveness, fraud, and batch endpoints.

    • Package: ekyc_sdk
    • Current version: 1.1.0
    • Source: github.com/CloudBhutan/ekyc-sdk-flutter
    • License: MIT

    Requirements¶

    • Dart SDK ≥ 3.0.0
    • Flutter ≥ 3.13.0 (when used in a Flutter app)

    The SDK pulls in camera, google_mlkit_face_detection, permission_handler, and path_provider for the active-liveness UI, plus http for API calls.

    Installation¶

    Add the package to your pubspec.yaml from Git:

    dependencies:
  ekyc_sdk:
    git:
      url: https://github.com/CloudBhutan/ekyc-sdk-flutter.git

    Or from a local checkout:

    dependencies:
  ekyc_sdk:
    path: ../ekyc-sdk-flutter

    Then:

    flutter pub get

    Platform Permissions¶

    The active-liveness UI uses the device camera. Add the standard permissions before publishing:

    iOS (ios/Runner/Info.plist):

    <key>NSCameraUsageDescription</key>
<string>Used for identity verification</string>

    Android (android/app/src/main/AndroidManifest.xml):

    <uses-permission android:name="android.permission.CAMERA" />

    Configuration¶

    import 'package:ekyc_sdk/ekyc_sdk.dart';

final config = EkycConfig(
  baseUrl: 'https://ekyc.cloudbhutan.com', // Required
  apiKey: 'your-api-key',                  // Sent as Bearer token
  timeout: const Duration(seconds: 60),    // Default: 30s
  headers: {'X-Custom': 'value'},          // Optional extra headers
);

final client = EkycClient(config);

    Always call client.close() when you no longer need the client to release the underlying HTTP connection.

    Quick Start¶

    Verify a selfie against the photo on an ID document:

    import 'dart:io';
import 'package:ekyc_sdk/ekyc_sdk.dart';

Future<void> main() async {
  final client = EkycClient(EkycConfig(
    baseUrl: 'https://ekyc.cloudbhutan.com',
    apiKey: 'your-api-key',
  ));

  try {
    final result = await client.verification.verifyFace(
      passportImage: File('passport.jpg'),
      liveImage: File('selfie.jpg'),
    );
    print('Verified: ${result.verified}');
    print('Similarity: ${result.similarity}');
  } finally {
    client.close();
  }
}

    Image Inputs¶

    All image parameters accept three forms — pick whichever fits the call site:

    import 'dart:io';
import 'dart:typed_data';

// From a File
await client.verification.detectFaces(image: File('photo.jpg'));

// From raw bytes
final Uint8List bytes = await File('photo.jpg').readAsBytes();
await client.verification.detectFaces(image: bytes);

// From a path string
await client.verification.detectFaces(image: '/path/to/photo.jpg');

    Feature Reference¶

    Verification¶

    // Face match
final v = await client.verification.verifyFace(
  passportImage: File('passport.jpg'),
  liveImage: File('selfie.jpg'),
);
// v.verified, v.distance, v.similarity, v.threshold

// Detect all faces in an image
final faces = await client.verification.detectFaces(image: File('photo.jpg'));
// faces.faces, faces.count

// Register an identity
await client.verification.registerFace(
  image: File('face.jpg'),
  identityId: 'person-123',
);

// Search the registered database
final search = await client.verification.searchFace(
  image: File('face.jpg'),
  threshold: 0.4,
  topK: 5,
);

// Detect duplicates
await client.verification.detectDuplicate(
  image: File('face.jpg'),
  threshold: 0.4,
);

    OCR¶

    // ID front (and optional back)
final doc = await client.ocr.ocrDocument(
  frontImage: File('id_front.jpg'),
  backImage: File('id_back.jpg'),
);
// doc.documentType, doc.fields, doc.confidence, doc.mrz

// Passport with VIZ + MRZ
final passport = await client.ocr.ocrPassport(image: File('passport.jpg'));

// MRZ-only extraction
final mrz = await client.ocr.ocrMrz(image: File('document.jpg'));

// Identify document type
final tmpl = await client.ocr.matchTemplate(image: File('document.jpg'));

    Liveness¶

    // Passive liveness check
final live = await client.liveness.livenessCheck(image: File('selfie.jpg'));
// live.isLive, live.confidence, live.checks

// Deepfake detection
final deep = await client.liveness.checkDeepfake(image: File('selfie.jpg'));

    Fraud Detection¶

    // Combined fraud analysis
final fraud = await client.fraud.detectFraud(image: File('doc.jpg'));
// fraud.isFraudulent, fraud.riskScore, fraud.checks

// Individual checks
await client.fraud.detectFakeDocument(image: File('doc.jpg'));
await client.fraud.detectPhotoSubstitution(image: File('doc.jpg'));
await client.fraud.detectTampering(image: File('doc.jpg'));
await client.fraud.detectCopyScreen(image: File('doc.jpg'));

// Validate document security features
await client.fraud.validateSecurityFeatures(
  image: File('doc.jpg'),
  documentType: 'national_id',
);

    Batch Processing¶

    // One-shot: submit and wait
final results = await client.batch.submitAndWait(
  images: [File('doc1.jpg'), File('doc2.jpg')],
  pollInterval: const Duration(seconds: 2),
  maxWait: const Duration(minutes: 5),
);

// Manual control
final job = await client.batch.submitBatch(images: [File('doc.jpg')]);
final status = await client.batch.getBatchStatus(jobId: job.jobId!);
final res = await client.batch.getBatchResults(jobId: job.jobId!);

    Health Check¶

    final isHealthy = await client.healthCheck();

    Error Handling¶

    All API failures throw EkycException:

    try {
  await client.verification.verifyFace(
    passportImage: File('a.jpg'),
    liveImage: File('b.jpg'),
  );
} on EkycException catch (e) {
  print('Error: ${e.message}');
  print('Status code: ${e.statusCode}');
  print('Response body: ${e.body}');
}

    Status codes follow the same conventions as the API reference — 400 for malformed requests, 413 for oversize files, 422 for validation errors, 429 for rate limiting, 500 for server errors.

    Testing¶

    Inject a mocked http.Client to write unit tests without hitting the network:

    import 'package:http/testing.dart';
import 'package:http/http.dart' as http;
import 'package:ekyc_sdk/ekyc_sdk.dart';

final mockClient = MockClient((request) async {
  return http.Response('{"verified": true}', 200);
});

final client = EkycClient(config, httpClient: mockClient);
