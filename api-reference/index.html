    eKYC API Reference¶

    Version: 1.0.0 · Last updated: April 2026 · Status: Production

    Overview¶

    The eKYC API provides a comprehensive suite of identity verification services including face verification, document OCR, liveness detection, fraud detection, AML screening, and more.

    Base URL¶

    https://ekyc.cloudbhutan.com/api/v1/

    API Versioning¶

    Version Prefix Status
    v1 /api/v1/ Current, stable
    v2 /api/v2/ Identical to v1, ready for future divergence

    You can also send an Accept-Version header (v1 or v2). All responses include an API-Version header. Deprecated endpoints return Deprecation: true, Sunset, and Link headers.

    Authentication¶

    All endpoints require an API key issued by Cloud Bhutan. Send it as a Bearer token in the Authorization header:

    curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://ekyc.cloudbhutan.com/api/v1/health

    Requests without a valid key return 401 Unauthorized. Contact Cloud Bhutan to obtain credentials.

    Content Types¶

    Scenario Content-Type
    Image uploads multipart/form-data
    JSON bodies application/json
    Mixed (image + form fields) multipart/form-data

    Supported Image Formats¶

    All image-accepting endpoints accept JPEG (image/jpeg) and PNG (image/png) only. Other formats return 400 Bad Request.

    Rate Limiting¶

    Tier Limit Applies To
    Standard 60 requests/minute per IP Most endpoints
    Heavy 10 requests/minute per IP Liveness, batch verify, face verify

    Rate limit headers on every response:

    Header Description
    X-RateLimit-Limit Requests allowed per window
    X-RateLimit-Remaining Requests remaining
    X-RateLimit-Reset Unix timestamp when the window resets

    Exceeding the limit returns 429 with a Retry-After header.

    Response Envelope¶

    Most endpoints return a flat JSON object. Errors follow this shape:

    {
  "error": "Short error description",
  "detail": "Detailed explanation"
}

    FastAPI validation errors (422):

    {
  "detail": [
    {
      "loc": ["body", "field_name"],
      "msg": "field required",
      "type": "value_error.missing"
    }
  ]
}

    1. Face Verification¶

    Endpoints for face comparison, detection, registration, 1:N search, duplicate detection, and age verification.

    POST /api/v1/verify-face¶

    Compare a live photo against a passport/document photo.

    Rate limit: Heavy (10/min)

    Request¶

    Parameter Type Required Description
    passport_image file ✅ Passport or document photo (JPEG/PNG)
    live_image file ✅ Live selfie photo (JPEG/PNG)

    Content-Type: multipart/form-data

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/verify-face \
  -F "passport_image=@passport.jpg" \
  -F "live_image=@selfie.jpg"

    Example Response¶

    {
  "match": true,
  "confidence": 0.9234,
  "distance": 0.3812,
  "threshold": 0.4,
  "face1_detected": true,
  "face2_detected": true
}

    Error Responses¶

    Status Condition
    400 Unsupported file type
    422 Missing required file
    429 Rate limit exceeded

    POST /api/v1/detect-faces¶

    Detect all faces in an image with bounding boxes and confidence scores.

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Description
    image file ✅ Image to analyze (JPEG/PNG)

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/detect-faces \
  -F "image=@photo.jpg"

    Example Response¶

    {
  "faces": [
    {
      "bbox": [120, 80, 320, 350],
      "confidence": 0.9987,
      "landmarks": [[165, 180], [270, 178], [215, 240], [175, 290], [265, 288]]
    }
  ],
  "count": 1
}

    POST /api/v1/register-face¶

    Register a face embedding in the database for 1:N matching.

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Description
    image file ✅ Face image (JPEG/PNG)
    identity_id string ❌ Unique identifier for this person. Auto-generated if omitted

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/register-face \
  -F "image=@face.jpg" \
  -F "identity_id=USER-001"

    Example Response¶

    {
  "identity_id": "USER-001",
  "registered": true,
  "face_detected": true,
  "embedding_stored": true
}

    POST /api/v1/search-face¶

    Search the face database for matches (1:N comparison).

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Default Description
    image file ✅ — Face image to search (JPEG/PNG)
    threshold float ❌ 0.4 Similarity threshold (lower = stricter)
    top_k int ❌ 5 Maximum number of results

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/search-face \
  -F "image=@probe.jpg" \
  -F "threshold=0.35" \
  -F "top_k=3"

    Example Response¶

    {
  "query_face_detected": true,
  "matches": [
    {
      "identity_id": "USER-001",
      "distance": 0.2815,
      "confidence": 0.9543
    }
  ],
  "total_matches": 1
}

    POST /api/v1/detect-duplicate¶

    Check if a face already exists in the database.

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Default Description
    image file ✅ — Face image (JPEG/PNG)
    threshold float ❌ 0.4 Distance threshold for duplicate match

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/detect-duplicate \
  -F "image=@face.jpg" \
  -F "threshold=0.35"

    Example Response¶

    {
  "is_duplicate": true,
  "matched_identity": "USER-001",
  "distance": 0.2103,
  "confidence": 0.9712
}

    POST /api/v1/verify-age¶

    Estimate age from a face image and compare against a date of birth.

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Description
    image file ✅ Face image (JPEG/PNG)
    date_of_birth string ✅ Date of birth in YYYY-MM-DD format

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/verify-age \
  -F "image=@face.jpg" \
  -F "date_of_birth=1990-05-15"

    Example Response¶

    {
  "estimated_age": 33,
  "document_age": 35,
  "age_difference": 2,
  "match": true,
  "confidence": 0.82,
  "tolerance_years": 5,
  "detection_score": 0.9945,
  "error": null
}
    Field Type Description
    estimated_age int \| null ML-estimated age from face
    document_age int \| null Calculated age from DOB
    age_difference int \| null Absolute difference
    match bool Whether difference ≤ tolerance_years
    confidence float Age estimation confidence
    tolerance_years int Allowed deviation (default 5)

    GET /api/v1/face-database/stats¶

    Get face database statistics.

    Rate limit: Standard (60/min)

    Example Request¶

    curl https://ekyc.cloudbhutan.com/api/v1/face-database/stats

    Example Response¶

    {
  "total_faces": 142,
  "total_identities": 138,
  "database_size_bytes": 524288
}

    DELETE /api/v1/face-database/clear¶

    Clear all stored face embeddings. Irreversible.

    Rate limit: Standard (60/min)

    Example Request¶

    curl -X DELETE https://ekyc.cloudbhutan.com/api/v1/face-database/clear

    Example Response¶

    {
  "cleared": true,
  "faces_removed": 142
}

    2. Document OCR¶

    Endpoints for extracting text and structured data from identity documents.

    POST /api/v1/ocr-document¶

    Universal document OCR — auto-detects document type and extracts fields. Supports passports, ID cards, driver's licenses, and more.

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Description
    front_image file ✅ Front side of the document (JPEG/PNG)
    back_image file ❌ Back side of the document (JPEG/PNG)

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/ocr-document \
  -F "front_image=@id_front.jpg" \
  -F "back_image=@id_back.jpg"

    Example Response¶

    {
  "document_type": "national_id",
  "confidence": 0.94,
  "fields": {
    "full_name": "DORJI TSHERING",
    "document_number": "10501001234",
    "date_of_birth": "1990-05-15",
    "nationality": "BTN",
    "expiry_date": "2030-12-31"
  },
  "raw_text": "KINGDOM OF BHUTAN..."
}

    POST /api/v1/ocr-passport¶

    Extract data from a passport image including MRZ and visual zone text. Legacy endpoint — prefer /ocr-document for new integrations.

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Description
    image file ✅ Passport image (JPEG/PNG)

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/ocr-passport \
  -F "image=@passport.jpg"

    Example Response¶

    {
  "mrz_data": {
    "document_type": "P",
    "country": "BTN",
    "surname": "TSHERING",
    "given_names": "DORJI",
    "document_number": "BT1234567",
    "nationality": "BTN",
    "date_of_birth": "900515",
    "sex": "M",
    "expiry_date": "301231"
  },
  "visual_zone": {
    "full_name": "DORJI TSHERING",
    "nationality": "BHUTANESE"
  },
  "confidence": 0.91
}

    POST /api/v1/ocr-mrz¶

    Extract only MRZ (Machine Readable Zone) data from a passport image.

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Description
    image file ✅ Passport image (JPEG/PNG)

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/ocr-mrz \
  -F "image=@passport.jpg"

    Example Response¶

    {
  "mrz_type": "TD3",
  "document_number": "BT1234567",
  "surname": "TSHERING",
  "given_names": "DORJI",
  "nationality": "BTN",
  "date_of_birth": "900515",
  "sex": "M",
  "expiry_date": "301231",
  "raw_mrz": "P<BTNTSHERING<<DORJI<<<<<<<<<<<<<<<<<<<<<\nBT12345674BTN9005152M3012318<<<<<<<<<<<<<<04"
}

    Error Response¶

    {
  "error": "No MRZ zone detected in image"
}

    POST /api/v1/match-template¶

    Match a document image against known document templates (passport, ID card, driver's license layouts).

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Description
    image file ✅ Document image (JPEG/PNG)

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/match-template \
  -F "image=@document.jpg"

    Example Response¶

    {
  "matched_template": "bhutan_national_id",
  "confidence": 0.87,
  "template_details": {
    "country": "BTN",
    "document_type": "national_id",
    "version": "2020"
  }
}

    POST /api/v1/batch/ocr-documents¶

    Process multiple document images concurrently (up to 4 at a time).

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Description
    files file[] ✅ List of document images (JPEG/PNG)

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/batch/ocr-documents \
  -F "files=@doc1.jpg" \
  -F "files=@doc2.jpg" \
  -F "files=@doc3.jpg"

    Example Response¶

    {
  "batch_id": "a3f1b2c8",
  "total": 3,
  "succeeded": 3,
  "failed": 0,
  "processing_time_ms": 2450.3,
  "results": [
    {
      "filename": "doc1.jpg",

    12. NFC Verification¶

    Verify NFC chip data from e-Passports and electronic ID documents. Parse DG1 (MRZ) and DG2 (biometric face) data groups.

    POST /api/v1/nfc/verify-chip¶

    Full NFC chip verification with optional document image cross-reference.

    Rate limit: Standard (60/min)

    Request¶

    Parameter Type Required Description
    chip_data string ✅ JSON string containing chip data (see schema below)
    document_image file ❌ Document photo for cross-reference (JPEG/PNG)

    Content-Type: multipart/form-data

    chip_data JSON schema:

    Field Type Required Description
    dg1 string ❌ Base64-encoded DG1 (MRZ data)
    dg2 string ❌ Base64-encoded DG2 (face biometric CBEFF)
    sod string ❌ Base64-encoded Security Object Document
    chip_auth bool ❌ Whether chip authentication succeeded on device
    bac_key object ❌ BAC key: {"doc_number": "...", "dob": "...", "expiry": "..."}

    Example Request¶

    curl -X POST https://ekyc.cloudbhutan.com/api/v1/nfc/verify-chip \
  -F 'chip_data={"dg1":"UDxCVE4uLi4=","dg2":"...","sod":"...","chip_auth":true}' \
  -F "document_image=@passport.jpg"

    Example Response¶

    {
  "chip_authentic": true,
  "mrz_parsed": true,
  "mrz_match": true,
  "face_match": true,
  "data_integrity": true,
  "chip_auth_reported": true,
  "parsed_fields": {
    "document_number": "BT1234567",
    "surname": "TSHERING",
    "given_names": "DORJI",
    "nationality": "BTN",
    "date_of_birth": "900515"
  },
  "details": {}
}
