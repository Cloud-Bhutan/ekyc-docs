    ### Application Lifecycle All ML models are loaded at startup in the `lifespan` context manager: 1. `FaceVerificationService` — loads InsightFace buffalo_l 2. `PassportOCRService` — loads PaddleOCR + MRZ detector 3. `DocumentOCRService` — wraps PassportOCR + template matching 4. `LivenessService` — loads anti-spoof-mn3, MediaPipe, and DeepfakeDetectionService 5. `DeepfakeDetectionService` — loaded by LivenessService, shared as `app.state.deepfake_service` 6. `FraudDetectionService` — stateless (no models, pure CV algorithms) 7. `SecurityFeatureService` — stateless (pure CV algorithms) 8. `BatchService` — in-memory job queue with ThreadPoolExecutor(4) Services are stored on `app.state` and accessed by routers via `request.app.state`. --- ## Service Layer Breakdown ### FaceVerificationService **File:** `app/services/face_verification.py` | Capability | Description | |-----------|-------------| | 1:1 Matching | Compare two face images using cosine similarity of embeddings | | Face Detection | Detect all faces with bounding boxes, age, gender | | Face Database | In-memory 1:N face store with register, search, duplicate detection | | Embedding | 512-D normalized face embeddings via InsightFace | **Model:** InsightFace `buffalo_l` (det_size=640×640), CPUExecutionProvider **Threshold:** Cosine similarity ≥ 0.4 for match --- ### DocumentOCRService **File:** `app/services/document_ocr.py` | Capability | Description | |-----------|-------------| | Auto-detection | Classifies document type from OCR text and field patterns | | MRZ Parsing | Detects and parses MRZ (TD1/TD3) with checksum validation | | VIZ Extraction | Regex-based field extraction (name, DOB, ID number, etc.) | | Template Matching | Structural matching against known document templates | | Portrait Extraction | Fast face extraction using OpenCV DNN (Caffe) | | Country Resolution | Maps nationality to specific card names (60+ countries) | **Pipeline:** Image → auto-downscale (≤1024px) → PaddleOCR → MRZ parse attempt → VIZ field extraction → document classification --- ### LivenessService **File:** `app/services/liveness.py` 6-layer weighted liveness scoring. See [Liveness Detection Pipeline](#liveness-detection-pipeline) for details. **Models loaded:** - anti-spoof-mn3 (ONNX) - MediaPipe Face Landmarker - DeepfakeDetectionService (ViT ONNX) --- ### DeepfakeDetectionService **File:** `app/services/deepfake_detection.py` Standalone ViT-based deepfake detector. Used both as a liveness layer and via the `/check-deepfake` endpoint. **Model:** Deep-Fake-Detector-v2 (ViT-B16), ONNX, ~343 MB **Pipeline:** Image → face extraction (Haar cascade) → multi-scale crop (1.0×, 2.0×) → ViT inference → weighted fusion (0.7/0.3) → deepfake probability --- ### FraudDetectionService **File:** `app/services/fraud_detection.py` Stateless document forensics using classical computer vision. See [Fraud Detection Pipeline](#fraud-detection-pipeline) for details. --- ### SecurityFeatureService **File:** `app/services/security_features.py` Stateless security feature validation. See [Security Feature Detection](#security-feature-detection) for details. --- ### BatchService **File:** `app/services/batch_service.py` | Property | Value | |----------|-------| | Max documents | 20 per job | | Concurrency | ThreadPoolExecutor with 4 workers | | Job TTL | 1 hour (auto-cleanup) | | Storage | In-memory dict | | Processing per doc | OCR → liveness (if face present) → fraud detection | --- ##     ### Layer Details | Layer | Weight | Model/Technique | What It Detects | |-------|--------|-----------------|-----------------| | **1. ML Anti-Spoof** | 0.35 | anti-spoof-mn3 (MobileNetV3) | Print attacks, replay attacks. Multi-scale inference at 1.0×, 2.7×, 4.0× crop sizes | | **2. Deepfake** | 0.20 | Deep-Fake-Detector-v2 (ViT-B16) | GAN-generated faces, face swaps. Score = 1 - P(deepfake) | | **3. 3D Depth** | 0.10 | MediaPipe z-coordinates | Flat images (prints/screens). Analyzes z-range, nose protrusion, ear depth, z-std | | **4. Texture** | 0.08 | Laplacian variance, edge density, noise analysis | Print/screen textures. Multi-region analysis, LBP-like local variance, noise patterns | | **5. Color & Frequency** | 0.07 | FFT, YCrCb skin detection | Moiré patterns, abnormal skin color, color banding, specular reflections | | **6. Context** | 0.20 | Hough lines, edge analysis | Document borders, text around face, face-to-image ratio, background uniformity | ### Anti-Spoof Model Details - **Input:** 128×128 RGB, normalized with mean=[151.24, 119.60, 107.84], scale=[63.01, 56.46, 55.00] - **Output:** [real_prob, spoof_prob] after softmax - **Multi-scale:** 3 crops (1.0×, 2.7×, 4.0×) averaged for robustness ### Deepfake ViT Details - **Input:** 224×224 RGB, rescaled 1/255, normalized mean=0.5 std=0.5 - **Output:** [P(Real), P(Deepfake)] after softmax - **Multi-scale:** 2 crops (1.0×, 2.0×) with weighted average (0.7/0.3) - **Heuristic fallback:** If ML model unavailable, uses ELA + FFT + texture + symmetry analysis --- ## Fraud Detection Pipeline 4 independent checks with weighted combination:

    HTTP Request (multipart/form-data)
         │
         ▼

  ├── Validate content type (JPEG/PNG only)
  ├── Read file bytes
  ├── Decode with cv2.imdecode (numpy array)
  │
  ▼
  asyncio.to_thread(service.method, image)
  │  (offload CPU-bound ML to thread pool)
  │
  ▼

  │  (all ML inference happens here)
  │
  ▼
  JSON response returned
    ### Key Design Decisions - **Thread offloading:** All ML inference runs via `asyncio.to_thread()` to avoid blocking the async event loop - **No persistent storage:** Face database and batch jobs are in-memory (reset on restart) - **Lazy model download:** Models auto-download on first startup, cached in `models/` directory - **Single-worker default:** Uvicorn runs with 1 worker (ML models are memory-intensive) - **GZip compression:** Responses >1 KB are compressed automatically --- ## Deployment Architecture ### Single Instance (Docker)
